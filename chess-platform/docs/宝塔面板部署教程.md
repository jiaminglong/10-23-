# 棋魂阁 - 宝塔面板部署教程

本文档介绍如何将棋魂阁部署到您自己的服务器（使用宝塔面板管理）。

## 一、环境要求

| 项目 | 要求 |
|------|------|
| 服务器 | 干净的 CentOS 7+ / Ubuntu 20+ / Debian 11+，最低 1核1G |
| 宝塔面板 | 7.x 及以上 |
| Python | 3.9 及以上（推荐 3.10/3.11） |
| Nginx | 任意较新版本（用于反向代理和 WebSocket 支持） |

## 二、安装宝塔面板（已装可跳过）

以 root 用户 SSH 登录服务器，执行对应脚本：

```bash
# Ubuntu / Debian
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && bash install.sh ed8484bec

# CentOS
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh ed8484bec
```

安装完成后记录面板地址、用户名和密码，浏览器登录。

## 三、上传代码

1. 打开宝塔面板左侧「文件」
2. 进入 `/www/wwwroot/`，新建目录 `chess-platform`
3. 将 `chess-platform.zip` 上传到该目录并解压
4. 解压后目录结构应为：

```
/www/wwwroot/chess-platform/
├── backend/
│   ├── app.py
│   ├── ai.py
│   ├── db.py
│   ├── games.py
│   ├── security.py
│   └── requirements.txt
└── frontend/
    ├── index.html
    ├── app.js
    └── style.css
```

## 四、安装 Python 项目管理器

1. 宝塔面板 →「软件商店」→ 搜索「Python项目管理器」→ 安装
2. 打开 Python 项目管理器 →「版本管理」→ 安装 Python 3.10（或 3.11）

## 五、创建 Python 项目

Python项目管理器 →「项目」→「添加项目」，按下表填写：

| 配置项 | 填写值 |
|--------|--------|
| 项目名称 | chess |
| 项目路径 | `/www/wwwroot/chess-platform/backend` |
| Python版本 | 3.10 |
| 框架/启动方式 | uvicorn |
| 启动方式/参数 | `app:app`（部分版本填写「启动文件 app.py、应用名 app」） |
| 端口 | 8000 |
| 安装依赖 | 勾选，依赖文件选 `requirements.txt` |
| 开机启动 | 勾选 |

> 关键点：`requirements.txt` 中使用的是 `uvicorn[standard]`，它自带 WebSocket 支持库。若项目启动日志出现 `No supported WebSocket library detected`，请在项目路径下手动执行：
>
> ```bash
> cd /www/wwwroot/chess-platform/backend
> pip3 install -r requirements.txt
> ```

启动成功后，可先验证：

```bash
curl http://127.0.0.1:8000/api/games
# 返回 JSON 即说明后端正常
```

## 六、配置 Nginx 反向代理（必须，含 WebSocket）

1. 宝塔面板 →「网站」→「添加站点」：填入域名（或先用 IP），PHP版本选「纯静态」
2. 点击该站点 →「反向代理」→「添加反向代理」：
   - 目标 URL：`http://127.0.0.1:8000`
   - 发送域名：`$host`
3. 添加后点击「配置文件」，找到 `#PROXY-END/`（或 proxy_pass 所在的 location 段），确认包含以下 WebSocket 相关头（缺少就补上）：

```nginx
location / {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;

    # WebSocket 支持（联机对战必需，缺失会导致匹配和对局无响应）
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";

    # 对局长连接保活时间
    proxy_read_timeout 300s;
    proxy_send_timeout 300s;
}
```

4. 保存并重载 Nginx。

## 七、放行端口

1. 宝塔面板 →「安全」→ 放行 `80`、`443`（若临时直连测试再放行 `8000`）
2. 云服务商控制台（阿里云/腾讯云等）→ 安全组 → 同样放行 `80`、`443`

## 十、常见问题

| 现象 | 原因与处理 |
|------|-----------|
| 能开网页但匹配/对局一直无反应 | Nginx 缺少 WebSocket 头，检查第六步 `Upgrade`/`Connection` 两行 |
| 日志报 `No supported WebSocket library detected` | 未装 `uvicorn[standard]`，手动 `pip3 install -r requirements.txt` 后重启项目 |
| 页面 502 | 后端项目未启动或端口不一致，在 Python项目管理器中查看项目日志 |
| 管理后台看不到部分标签页 | 只有 `role=author` 才有完整标签；`admin` 角色权限较少属正常 |
| 邮件/通知收不到 | 检查管理后台是否已发送；全站邮件 `to_user=0` 表示全员 |
| 修改代码后不生效 | Python项目管理器中「重启」项目；浏览器 Ctrl+F5 强刷前端缓存 |
